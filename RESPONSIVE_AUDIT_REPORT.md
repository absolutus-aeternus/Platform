## Ringkasan Kode Hasil Refactoring

### 1. `src/layouts/AdminLayout.vue`
**Before:** Dua media query `@media (max-width: 768px)` yang saling konflik — satu menyembunyikan sidebar, satu lagi mencoba menjadikannya bottom navigation bar.

**After:** Satu media query bersih yang:
- Mengubah sidebar menjadi off-canvas drawer (`transform: translateX(-100%)`)
- Menampilkan sidebar saat `sidebar-collapsed` class aktif
- Menambahkan overlay backdrop semi-transparan
- Menyembunyikan search box dan text user dropdown
- Mengurangi padding page-content

### 2. `src/assets/responsive.css`
**Before:** `.table-wrapper` tidak memiliki `overflow-x: auto` — tabel admin yang lebar terpotong di mobile.

**After:** 
- Menambahkan `.table-wrapper` ke selector `overflow-x: auto`
- Menambahkan `min-width: 600px` pada tabel di dalam `.table-wrapper` pada mobile untuk memastikan tabel bisa di-scroll horizontal
